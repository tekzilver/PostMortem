PostMortem Forensic Log Analyzer V1.0:
PostMortem is a read-only, zero-tech forensic log analyzer built by Tekzilver. It is designed for cybersecurity researchers and professionals to safely ingest Apache, Nginx, CSV, and JSON access logs to investigate breaches, trace malicious IP activity, and detect web shells or SQLi/XSS attacks.

Features:
1. Zero-Tech Query Wizard: Easily find "Who accessed resource?" or "Trace IP across domains".
2. Threat Intelligence Engine: Automatic detection of SQLi, XSS, RFI, Path Traversal, and Obfuscated Base64 payloads.
3. Forensic Integrity: Cryptographic SHA-256 and MD5 hashing for chain-of-custody verification.
4. Case Management: Create isolated investigation cases (TEKYYYYMMDD-X).
5. Professional Reporting: Generate paginated, column-selectable A4 PDF/Print reports.
6. IP Geolocation: Integrated ipinfo.io API for ASN, Domain, and Country tracing.

Download & Install:
1. Go to the Releases page.
2. Download the PostMortem Setup 1.0.0.exe file.
3. Run the installer and launch PostMortem.
   
Note: Windows SmartScreen may show a warning because the app is not digitally signed by Microsoft. Click "More info" and then "Run anyway" to proceed.
